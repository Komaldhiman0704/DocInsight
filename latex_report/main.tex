\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

DocInsight is a full-stack, privacy-preserving document intelligence platform that
enables natural language question answering over user-uploaded documents using the
Retrieval-Augmented Generation (RAG) architecture. The system addresses three
fundamental limitations of standalone large language models: knowledge confined to
training data, susceptibility to hallucination, and absence of verifiable source
attribution.

The platform integrates a FastAPI backend, LangChain RAG orchestration, ChromaDB
local vector store, and a React single-page application frontend. Documents in PDF,
DOCX, and TXT formats are ingested, chunked into 1,000-character segments with
200-character overlap, and embedded locally using the \texttt{all-MiniLM-L6-v2}
sentence transformer model (384-dimensional vectors). At query time, the top-$k$
semantically relevant chunks are retrieved via cosine similarity and provided as
grounded context to a streaming large language model, ensuring every response is
traceable to specific source pages.

Key features of the implemented system include real-time token streaming via
Server-Sent Events, clickable source citations with direct PDF viewer navigation,
persistent session management, automatic document summarisation, chat export to PDF,
and browser-based voice input. The local-first architecture ensures that no
document content is transmitted to external servers during the embedding or retrieval
stages, satisfying data privacy and sovereignty requirements.

System testing confirmed reliable operation across all supported file formats, correct
source attribution following a page indexing normalisation fix, and sub-5-second
end-to-end query latency under typical conditions. The project demonstrates that
production-grade document intelligence, combining explainability, privacy, and
verifiable source grounding, can be achieved using entirely open-source, locally
deployable components.
