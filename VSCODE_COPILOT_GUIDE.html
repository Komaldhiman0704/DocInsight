Set Up Groq API Key

The free AI brain — takes 2 minutes

Required Pending
ℹ
Groq is completely free. No credit card. 10 million tokens/month free. Sign up takes 60 seconds.
1

Get your free API key

Steps to get key
1. Open browser → go to: https://console.groq.com/keys
2. Click "Sign Up" (use Google or GitHub account)
3. Click "Create API Key"
4. Give it any name (e.g. "pdf-chatbot")
5. COPY the key immediately — it starts with "gsk_"
   (You won't be able to see it again after closing!)
2

Add the key to the project

In VSCode Explorer (left panel): click backend → click .env

Find this line and replace with your key:

backend/.env — change this line
GROQ_API_KEY=your_groq_api_key_here   ← BEFORE (delete this)
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxx   ← AFTER (paste your key)

Press Ctrl+S to save the file.

⚠
Never share your .env file or commit it to GitHub. It contains your secret key.

⚡ Common Errors — Quick Fixes

If you hit an error, copy the message and paste it into Copilot Chat saying "I got this error: [paste]. How do I fix it?"

ErrorWhat it means & fix
'python' is not recognized Python not in PATH. Reinstall Python from python.org, check "Add Python to PATH" during install. Then restart VSCode.
venv\Scripts\activate not recognized You're in PowerShell with execution policy blocked. Run: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser then try again.
chromadb install fails Run: pip install chromadb --upgrade. If still failing, try: pip install chromadb==0.5.15 --no-cache-dir
GROQ_API_KEY not set / invalid Open backend/.env, make sure key starts with gsk_ and is not the placeholder text. Save the file (Ctrl+S).
Port 8000 already in use Another app is using port 8000. Run: netstat -ano | findstr :8000, then kill that process, or change to port 8001.
npm: command not found Node.js not installed. Go to nodejs.org, install LTS version, restart VSCode.
First upload very slow (60s+) Completely normal! HuggingFace embedding model downloads once (~90MB). All future uploads take seconds.
Frontend shows blank white page Open browser dev tools (F12) → Console tab → paste the red error into Copilot.
CORS error in browser console Backend isn't running. Check Terminal 1 shows "Application startup complete". Restart it if needed.
