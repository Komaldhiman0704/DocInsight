# Complete VSCode + GitHub Copilot Guide
# AI PDF Chatbot — From Zero to Running

=======================================================
 READ THIS FULLY BEFORE STARTING — 15 min total setup
=======================================================

## WHAT YOU WILL DO (Overview)
1. Install VSCode + extensions
2. Open the project folder
3. Open Copilot Chat
4. Copy-paste commands from this guide into Copilot
5. App runs at http://localhost:5173

No prior experience needed. Every step is explained.

=======================================================
## PHASE 1 — INSTALL VSCODE (skip if already installed)
=======================================================

1. Go to: https://code.visualstudio.com
2. Click "Download for Windows"
3. Run the installer
4. IMPORTANT — during install, check ALL these boxes:
   ✓ Add "Open with Code" action to Windows Explorer
   ✓ Add to PATH (important!)
   ✓ Register Code as editor for supported file types
5. Click Install → Finish

=======================================================

=======================================================

Open VSCode. Press Ctrl+Shift+X to open Extensions panel.

Install these one by one (search and click Install):

  1. "GitHub Copilot"          by GitHub
  2. "GitHub Copilot Chat"     by GitHub
  3. "Python"                  by Microsoft
  4. "Pylance"                 by Microsoft
  5. "ESLint"                  by Microsoft

After installing GitHub Copilot:
  → VSCode will ask you to Sign in with GitHub
  → Click "Sign in to GitHub"
  → Login in the browser that opens
  → Come back to VSCode

If you don't have GitHub Copilot subscription:
  → Go to: https://github.com/features/copilot
  → Students get it FREE via GitHub Student Developer Pack
  → Or use the 30-day free trial

=======================================================
## PHASE 6 — SET UP GROQ API KEY (FREE)
=======================================================

You need a free Groq API key. This is the AI brain.

STEP 1: Get the key
  → Open browser → go to https://console.groq.com/keys
  → Sign up (it's free, no credit card)
  → Click "Create API Key"
  → Copy the key (starts with "gsk_")

STEP 2: Add to project
  → In VSCode Explorer (left panel), click: backend → .env
  → The file opens in the editor
  → Find this line:
       GROQ_API_KEY=your_groq_api_key_here
  → Replace with your actual key:
       GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxx
  → Press Ctrl+S to save

STEP 3: Ask Copilot to verify
─────────────────────────────────────────────────────
@workspace Check the backend/.env file and tell me 
if the GROQ_API_KEY looks correctly set (starts with gsk_).
Don't show me the full key, just confirm the format is right.
─────────────────────────────────────────────────────

=======================================================
## PHASE 7 — SET UP PYTHON BACKEND (paste into Copilot)
=======================================================

PASTE THIS into Copilot Chat:

─────────────────────────────────────────────────────
@workspace Set up the Python backend for this project.
Run these commands in the terminal step by step:

1. Navigate to the backend folder:
   cd backend

2. Create a Python virtual environment:
   python -m venv venv

3. Activate it (Windows):
   venv\Scripts\activate

4. Upgrade pip:
   python -m pip install --upgrade pip

5. Install all dependencies:
   pip install -r requirements.txt

Run each command and wait for it to finish before the next.
Tell me when each step completes or if there are any errors.
─────────────────────────────────────────────────────

THIS WILL TAKE 3-5 MINUTES. You'll see lots of text scrolling.
That is normal — it's downloading packages.

When done, Copilot will confirm. If you see errors, paste them
back into Copilot and say "fix this error".

## PHASE 10 — OPEN TWO TERMINALS AND RUN THE APP
=======================================================

You need TWO terminals running at the same time.
VSCode can do this easily.

--- TERMINAL 1: Backend ---

PASTE THIS into Copilot Chat:

─────────────────────────────────────────────────────
@workspace Open a new terminal and start the backend server.
Run these commands:
   cd backend
   venv\Scripts\activate
   uvicorn main:app --reload --port 8000

The server should say "Application startup complete"
and "Uvicorn running on http://0.0.0.0:8000"
─────────────────────────────────────────────────────

When you see "Uvicorn running on http://0.0.0.0:8000"
the backend is ready. KEEP THIS TERMINAL OPEN.

--- TERMINAL 2: Frontend ---

Now create a SECOND terminal:
  → In VSCode, press Ctrl+Shift+` (backtick key)
  → OR: Terminal menu → New Terminal
  → You'll see a "+" button in the terminal panel — click it

PASTE THIS into Copilot Chat (second session):

─────────────────────────────────────────────────────
@workspace In this new terminal, start the frontend 
development server:
   cd frontend
   npm run dev

It should say "Local: http://localhost:5173"
─────────────────────────────────────────────────────

When you see "Local: http://localhost:5173" → the app is ready!

## COMMON ERRORS — WHAT TO DO
=======================================================

If you see an error at any point, do this:

1. Copy the EXACT error text
2. Go to Copilot Chat
3. Paste and say: "I got this error, how do I fix it?"

Common ones:

ERROR: "python is not recognized"
→ Paste into Copilot: "python is not recognized as a command,
   how do I fix this on Windows?"
→ Fix: Reinstall Python, check "Add to PATH"

ERROR: "venv\Scripts\activate is not recognized"  
→ Paste into Copilot: "venv activation failed on Windows,
   how do I fix this?"
→ Fix: Run in PowerShell instead of CMD

ERROR: chromadb install fails
→ Paste into Copilot: "chromadb pip install failed with this
   error: [paste error]. How do I fix it?"
→ Fix usually: pip install chromadb --upgrade

ERROR: "GROQ_API_KEY not set"
→ Open backend/.env → check key starts with gsk_
   and is not the placeholder text

ERROR: "npm: command not found"
→ Install Node.js from https://nodejs.org

ERROR: Port 8000 already in use
→ Paste into Copilot: "Port 8000 is already in use, 
   how do I kill the process and restart?"

ERROR: First upload takes very long
→ Normal! Say: "The first PDF upload is taking 60+ seconds,
   is this normal?" → Copilot will confirm it's the model download
